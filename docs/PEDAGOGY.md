# Pedagogy

Every mission follows the same mastery loop:

1. **Discover** — what is it?
2. **Experience** — interact with a synthetic incident.
3. **Decide** — choose an action.
4. **Consequence** — see what the choice changed.
5. **Law** — connect to a principle.
6. **Test** — answer the mastery check.
7. **Unlock** — next mission becomes available only after passing.

The final message is intentionally explicit: **You learned Cyber Law through hands-on investigation.**
